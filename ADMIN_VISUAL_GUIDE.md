## Color Scheme

### Status Colors
- 🟢 **Green** - Confirmed, Verified, Success
- 🟡 **Yellow** - Pending, Warning, Awaiting
- 🔴 **Red** - Cancelled, Rejected, Error
- 🔵 **Blue** - Info, Notice, Neutral
- ⚪ **Gray** - Inactive, Disabled, Unknown

### Gradient Cards
- **Blue Gradient** - Primary stats (Aquariums, Bookings)
- **Purple Gradient** - User stats
- **Pink Gradient** - User metrics
- **Green Gradient** - Revenue, Success metrics
- **Orange Gradient** - Pending, Warning metrics

## Responsive Behavior

### Desktop (1920x1080)
- Full sidebar visible
- 4 columns for stat cards
- Charts side-by-side
- Full table width

### Laptop (1366x768)
- Full sidebar visible
- 4 columns for stat cards
- Charts stacked
- Table scrolls horizontally

### Tablet (768x1024)
- Collapsible sidebar
- 2 columns for stat cards
- Charts stacked
- Table scrolls horizontally

### Mobile (375x667)
- Hamburger menu
- 1 column for stat cards
- Charts stacked
- Table scrolls horizontally
- Simplified filters
